Pytende - design system

Referência visual das quatro telas do Pytende (Login, Lista, Novo e Edição). Os valores vêm do design system da Wise, com Inter no lugar da Wise Sans. Antes de escrever um template, confira aqui o componente e use só os tokens de static/css/tokens.css.

Anel de sombra e anel de foco

A elevação vem do contraste de superfície. Só as mensagens usam o anel de sombra. Todo elemento focado pelo teclado mostra o anel de foco.

--shadow-ring: 0 0 0 1px #868685
--focus-ring: 0 0 0 2px #ffffff, 0 0 0 3px #0e0f0c
